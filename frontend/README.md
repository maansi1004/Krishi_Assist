# KrishiAssist Frontend

Professional, agriculture-themed React/Vite landing page for KrishiAssist. The homepage is intentionally image-led and clean rather than icon-heavy.

## Run

```bash
npm install
npm run dev
```

The frontend expects the FastAPI backend at `http://localhost:8000`. Set `VITE_API_URL` to change it.

## Design notes

- Responsive/mobile-first layout
- Automatic hero image slideshow with manual controls
- English / Hindi / Hinglish selector
- Natural-language farmer need search
- Service photography
- Live featured scheme cards from `/api/schemes`
- Professional government/agriculture visual language
